# 📱 SamiSocial - Frontend

A modern social media web application built to explore full-stack web development concepts. SamiSocial allows users to create accounts, share posts, interact with content, and experience a responsive social networking platform.

## 🚀 Features

* Create and Manage Posts
* Responsive Design
* Modern User Interface
* Frontend & Backend Integration

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

SamiSocial was built as a learning project to strengthen my understanding of full-stack web development, including frontend design, backend development, database integration, and deployment.

## 📚 What I Learned

* Building responsive user interfaces
* Creating RESTful APIs
* Handling user authentication
* Connecting frontend and backend systems
* Working with databases
* Deploying web applications

## 🔮 Future Improvements
